# Contributing to CampusFlow AI

Thank you for your interest in contributing to CampusFlow AI!

## Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Ensure TypeScript types compile cleanly (`npm run build`).
3. Run `python generate_evidence.py` to verify that RL reward curves and evaluation metrics remain valid.
4. Submit a Pull Request describing your changes.
