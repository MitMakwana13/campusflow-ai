# Changelog

All notable changes to CampusFlow AI will be documented in this file.

## [1.0.0-RC1] - 2026-07-24
### Added
- Gymnasium-based PPO Reinforcement Learning engine (`rl/envs/timetable_env.py`).
- Rule-based Schedule Validator supporting `HIGH`, `MEDIUM`, `LOW` severities and suggested fix recommendations.
- Multi-Algorithm Benchmark Suite comparing Manual, Rule-Based, Greedy, and PPO solvers.
- Database versioning and `optimization_runs` audit history.
- Printable Executive HTML/PDF Optimization Audit Report generator.
- One-click Schedule Version Rollback system.
- Next.js 15 UI with Repository pattern abstraction.
- Comprehensive 10-part documentation suite in `docs/`.
- One-command Docker Compose setup.
