# CampusFlow AI — Administrator User Guide

## Step-by-Step Walkthrough
1. **View Schedule**: Navigate to `http://localhost:3000/timetable`.
2. **Review Conflicts**: Notice active red clash warnings (e.g., Room B-222).
3. **Run Optimization**: Click **Run Optimization** button.
4. **Review Metrics**: Inspect Before vs After performance modal (-760 -> +240 pts).
5. **View AI Explanation**: Read the structured recommendation and constraint trace.
6. **Download Report**: Click **PDF Report** to export printable audit report.
7. **Rollback State**: Click **Rollback** to revert schedule to manual baseline.
